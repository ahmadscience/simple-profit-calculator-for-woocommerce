# Security Policy

## Supported versions

Security fixes are released for the latest version of the plugin.

| Version | Supported |
| ------- | --------- |
| 2.x     | ✅        |
| < 2.0   | ❌        |

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues or the WordPress.org support forum.**

Report them privately through GitHub:

👉 [**Report a vulnerability**](https://github.com/ahmadscience/simple-profit-calculator-for-woocommerce/security/advisories/new)

Please include:

- the plugin version, and the WordPress, WooCommerce and PHP versions,
- what an attacker can do and which user role they need,
- steps to reproduce or a proof of concept.

You will get a reply within 7 days. Once a fix is released you'll be credited in the changelog unless you prefer otherwise.

If you can't use GitHub, you can also report through the [Patchstack](https://patchstack.com/database/report) or [Wordfence](https://www.wordfence.com/threat-intel/vulnerabilities/submit) vulnerability disclosure programs.
